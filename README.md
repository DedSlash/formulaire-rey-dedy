# Formulaire de projet — Rey Dedy Pangou

Formulaire de prise de brief pour mes prestations de développement web fullstack.

Page statique (HTML + CSS + JS, sans dépendance externe) qui collecte les
informations d'un projet et propose au client **deux modes d'envoi** :

- **WhatsApp** — ouvre une conversation pré-remplie sur `wa.me/221781602037`
- **Email** — envoie les données via l'API [Web3Forms](https://web3forms.com/)

Le formulaire est bilingue (français / anglais) et inclut les étapes :
identité, description du projet, budget et délai.

## Déploiement

Le fichier `formulaire_projet_rey_dedy.html` est servi à la racine du site
grâce au fichier `_redirects` (Netlify). Aucun build n'est nécessaire :
n'importe quel hébergeur statique fait l'affaire.
